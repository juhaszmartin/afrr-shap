# aFRR imbalance forecasting with SHAP

Short-term forecasts of the imbalance price (Long/Short) and imbalance volume for 17 European countries, with SHAP explanations of what drives them. One neural network per country predicts all targets 15–75 min ahead (15-min countries) or 1–2 h ahead (hourly countries). 2025 is the test year everywhere.

**[PIPELINE.md](PIPELINE.md) is the full documentation**: data sources, every preprocessing step, the model, SHAP, built-in assumptions, known issues and the current results.

## Quickstart

```bash
python -m venv venv
venv/bin/pip install -r requirements.txt   # tested with Python 3.14.6
venv/bin/pip install -e .
./run_pipeline.sh                          # preprocess -> train -> SHAP -> plots
```

Default pipeline settings live in `configs/default.yaml`; country metadata is in
`configs/countries.yaml`. The baseline experiment is captured in
`configs/experiments/baseline.yaml`.
Set `AFRR_CONFIG=configs/experiments/baseline.yaml` to run with another
configuration file.

The installed `afrr` CLI exposes the same stages:

```bash
afrr preprocess --countries DE,FR
afrr train --countries DE,FR
afrr explain --countries DE,FR
afrr report
afrr pipeline
```

`run_pipeline.sh` needs the raw data in `data/raw/entsoe/` and `data/raw/weather/` (see below). On a GPU the full run takes a few hours; most of it is training 100 seeds per country and SHAP. Steps can be run per country, e.g. `venv/bin/python scripts/train_all_100_seeds.py DE,FR`.

## Data

The raw data is **not in the repository** (`data/raw/entsoe/` is about 570 MB, `data/raw/weather/` about 270 MB).

| Source | Folder | Script | Credentials |
|---|---|---|---|
| ENTSO-E Transparency Platform | `data/raw/entsoe/` | `scripts/fill_entsoe_gaps.py` fills and checks the stored files | `ENTSOE_API_KEY=...` in `.env` |
| ERA5 reanalysis (Copernicus CDS) | `data/raw/weather/` | `scripts/era5_download.py` | `CDSAPI_URL=...` and `CDSAPI_KEY=...` in `.env` |
| ECB euro reference rates | `data/reference/ecb_eur_rates.csv` (in the repo) | `scripts/get_fx_rates.py` | none |

`.env` is gitignored; never commit it. Copy `.env.example` to `.env` and fill in the keys from the table; the download scripts load it themselves, so no shell setup is needed. The script that made the original bulk ENTSO-E download is not part of the repository. `fill_entsoe_gaps.py` only adds missing timestamps to existing files and replaces single years (`refresh`), see PIPELINE.md §3.1.

## Layout

| Path | Content |
|---|---|
| `scripts/` | the pipeline (see PIPELINE.md §2) |
| `data/processed/` | feature and target matrices per country (generated, gitignored) |
| `models/` | trained weights and scalers (generated, gitignored) |
| `results/` | metrics per country and target, and a combined text summary |
| `figures/` | SHAP tables (`shap_mean_abs_*`, `shap_category_*`, `shap_stability_*`) and summary plots; `figures/performance/` has the metric charts from `plot_results.py` |
| `samples/` | 3-day plots of forecasts against actuals |
| `entsoe_availability.md` | the input series each country ends up with (generated by `scripts/get_entsoe_info.py`) |
| `legacy/` | superseded scripts and notebooks, kept for reference |

## Reproducibility

- Package versions are pinned in `requirements.txt`.
- Seeds are fixed (training seeds 0–99, SHAP sample seed 42), but PyTorch does not run deterministically on the GPU, so metrics reproduce to within a small tolerance rather than bit for bit (PIPELINE.md §6).
- ENTSO-E data is revised by the TSOs after publication, so a fresh download can differ from the stored files (PIPELINE.md §3.1).
